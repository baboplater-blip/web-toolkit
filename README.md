## 작업 한 바퀴는 이렇게 돕니다

```
        goal.md           plan.md          (구현)          test.md          status.md
       무엇을 위해   →   어떻게 / 무엇을   →   도메인 분할   →   게이트 7단계   →   결과 기록
        (목표·DoD)       (절차·다음후보)      병렬 작업        전부 초록?         (진행 갱신)
                                              ↑                                      │
                                              └───────── rules.md (항상 지킴) ───────┘
```

1. **goal** 에서 "왜/무엇" 을 확인하고
2. **plan** 에서 "이번 라운드에 무엇을, 어떻게" 를 정하고
3. **rules** 를 어기지 않으며 구현하고
4. **test** 의 게이트를 전부 통과시키고
5. **status** 에 결과를 적고 다음 후보를 제시합니다.

> 한 라운드가 "끝났다"는 판정은 **오직 [test.md](test.md) 의 게이트가 전부 초록불**일 때입니다.

## 빠른 시작 (개발자용)

```powershell
cd web-toolkit\web
npm install          # 최초 1회
npm run dev          # 로컬 개발 서버
```

검증(게이트)을 한 번에 돌리는 방법은 **[test.md](test.md) §1 복붙 실행** 을 보세요.

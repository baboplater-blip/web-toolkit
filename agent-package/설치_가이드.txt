================================================================
  Agent Control Panel - PC Agent 설치 가이드
================================================================

이 폴더를 대상 PC 에 복사하면 해당 PC 를 웹에서 원격 제어할 수 있습니다.
제어는 핸드폰 또는 다른 PC 에서 웹 앱으로 접속해 수행합니다.

  웹 주소 : 본인 Vercel 배포 도메인 (예: https://your-domain.vercel.app)

※ 로그인 계정은 각자 본인 것을 쓰세요. 공유 계정을 만들지 마세요.


================================================================
  사전 준비 (이미 설치되어 있으면 건너뛰세요)
================================================================

1. Node.js LTS 설치
   https://nodejs.org 에서 LTS 버전 다운로드 후 설치.

2. Claude Code 설치
   터미널(cmd / PowerShell) 에서:
     npm install -g @anthropic-ai/claude-code

3. Claude Code 로그인
   터미널에서:
     claude
   (최초 1회 로그인 필요)


================================================================
  권장 설치 방법 - 원클릭 (PowerShell)
================================================================

1) 웹에서 "PC 추가" → PC 이름 입력 → 원라인 설치 명령 복사
2) 대상 PC 에서 PowerShell(관리자 권장)을 열고 붙여넣기:

   irm https://<your-domain>/api/install/<token> | iex

설치 스크립트가 Node.js 확인 → 파일 다운로드 → 서버에 토큰 교환 → .env 작성 → 패키지 설치 → 에이전트 기동까지 자동 수행합니다.

※ 설치 토큰은 1 회용·24 시간 유효입니다.
※ PC .env 에는 공개 anon key + agent api_key 만 저장되며, Supabase Service Role Key 는 절대 저장되지 않습니다.


================================================================
  수동 설치 (배치 파일/토큰 방식)
================================================================

1. 이 폴더를 원하는 위치에 복사합니다. (예: C:\agent-control-panel)

2. install.bat 을 더블클릭합니다.
   - Node.js 확인
   - npm install
   - `npx tsx src/setup.ts` 자동 실행
   - 여기서 물어보는 순서:
       · 웹 주소 (API_BASE_URL)
       · 설치 토큰 (웹 > PC 추가 에서 발급한 16 자)
       · SUPABASE_URL / SUPABASE_ANON_KEY (공개 값 — 웹 앱의 .env.local.example 참고)

3. start.bat 을 더블클릭 → 에이전트가 기동되고 웹에서 이 PC 가 온라인으로 표시됩니다.


================================================================
  .env 에 들어가는 값 (전부 공개 가능한 값만)
================================================================

SUPABASE_URL         = Supabase 프로젝트 URL (공개)
SUPABASE_ANON_KEY    = Supabase anon(공개) 키
API_BASE_URL         = 본인 Vercel 도메인
AGENT_API_KEY        = 이 PC 고유 키 (install_token 교환으로 자동 발급)
AGENT_USER_ID        = 이 에이전트를 소유한 Supabase 사용자 UUID

선택:
DANGEROUSLY_SKIP_PERMISSIONS=1   # Claude Code 권한 승인 건너뛰기 (기본 OFF)
TASK_TIMEOUT_MS=300000           # 작업 타임아웃 (ms)
ANTHROPIC_API_KEY=sk-ant-...     # BYOK 모드 — 있으면 Claude Max 구독 대신 Anthropic API 로 과금


================================================================
  보안 참고
================================================================

- Service Role Key 는 **절대** PC 에 내려받지 마세요. 이 프로젝트의 현재 설치 방식은
  서버가 공개 anon key + 에이전트 JWT 만 발급하며, Service Role Key 는 Vercel 서버 환경에만 존재합니다.
- AGENT_API_KEY 가 유출되면 해당 PC 의 명령 실행 권한이 탈취됩니다. 웹의 "PC 삭제 / 재발급" 으로 즉시 무효화하세요.
- 기본적으로 Claude Code 의 권한 승인을 건너뛰지 않습니다. 파일 쓰기 같은 작업은
  에이전트 콘솔에서 권한 확인이 뜰 수 있습니다 (자동화가 필요할 때만 opt-in).


================================================================
  BYOK 모드 (Anthropic API 직접 사용)
================================================================

기본은 Claude Max 구독으로 동작합니다. 구독이 없거나 별도 API 키로
과금하고 싶다면 다음 값을 .env 에 추가하세요:

  ANTHROPIC_API_KEY=sk-ant-...

에이전트가 시작할 때 이 값을 감지해서 자동으로 BYOK 모드로 표시되고,
웹 UI 의 PC 목록에서도 "API" 뱃지가 뜹니다. 비용은 본인 Anthropic 계정에
청구되며, 내부적으로는 동일한 Claude CLI 가 ANTHROPIC_API_KEY 를 읽어
API 호출로 동작합니다.


================================================================
  자동 시작 설정 (선택)
================================================================

PC 부팅 시 자동 실행:

1. npm install -g pm2
2. 이 폴더에서: pm2 start ecosystem.config.js
3. pm2 save && pm2-startup install


================================================================
  문제 해결
================================================================

Q: 에이전트가 "auth 401" 로 시작 실패합니다.
A: AGENT_API_KEY 가 잘못되었거나 삭제되었습니다. 웹에서 PC 를 다시 추가하세요.

Q: "claude: command not found"
A: Claude Code 미설치. npm install -g @anthropic-ai/claude-code 후 claude 로 로그인.

Q: 웹에서 PC 가 오프라인으로 표시됩니다.
A: start.bat 이 실행 중인지 확인. 종료했으면 다시 실행.

Q: 하네스가 안 보입니다.
A: Desktop, Documents, Projects 폴더에서 CLAUDE.md 파일을 자동 검색합니다.
   경로 추가는 src/harness.ts 의 SEARCH_PATHS 참조.

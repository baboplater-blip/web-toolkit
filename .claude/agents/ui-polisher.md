너는 도구들의 UX 일관성을 유지한다. 도구가 50개 넘어가도 사용자가 한 번 익힌 패턴이 어디서나 그대로 통하도록 만든다.

## 공통 컴포넌트

- `web/src/components/tools/FileDropZone.tsx` — 드래그&드롭 + 클릭 선택
- `web/src/components/tools/ResultCard.tsx` — 결과 미리보기 + 다운로드
- 새 패턴이 3개 이상 도구에서 반복되면 → 공통 컴포넌트로 승격

## 표준 페이지 레이아웃

```
┌─────────────────────────────────┐
│ 헤더 (도구명 + 짧은 설명)         │
├─────────────────────────────────┤
│ 입력: FileDropZone               │
├─────────────────────────────────┤
│ 옵션 패널 (있을 때만)             │
├─────────────────────────────────┤
│ [처리 시작] 버튼 + 진행률          │
├─────────────────────────────────┤
│ 결과: ResultCard (성공 시)        │
│ 에러: 빨간 알림 (실패 시)          │
└─────────────────────────────────┘
```

`max-w-2xl mx-auto p-4 space-y-4` 가 기본 컨테이너.

## 모바일 우선 규칙

- 버튼 hit area 최소 44×44 px (Tailwind `h-11`)
- 드롭존은 모바일에서 클릭하면 파일 피커
- 결과 다운로드 버튼은 항상 화면 하단(엄지 도달)
- 가로 스크롤 절대 금지

## 다크모드

shadcn/ui 토큰 사용 시 자동:
- `bg-card text-card-foreground border` — 카드
- `text-muted-foreground` — 보조 텍스트
- `text-primary` — 강조

`bg-white text-black` 같은 직접 색상 금지.

## 진행률 표시

- 0–100% 결정형: `<Progress value={percent} />`
- 미정형(스피너): `<Loader2 className="animate-spin" />`
- 5초 이상 걸리는 작업은 반드시 진행률
- 진행률 옆에 **취소** 버튼 항상 노출

## 에러 표시 톤

- 한국어로 짧고 명확하게
- "변환에 실패했어요. 파일이 손상되었을 수 있습니다."
- "이 파일은 너무 큽니다(150 MB). 100 MB 이하를 권장합니다."
- 기술적 스택트레이스는 콘솔로만

## 빈 상태

도구 페이지 진입 시 드롭존 안내 한 줄 + 지원 포맷 칩.

# 한국어 UI 컨벤션

## 톤

- **존댓말 기본** ("선택해주세요", "처리되었습니다")
- 간결: "파일을 선택해주세요" > "여기에 파일을 선택해서 올려주세요"
- 명령형보다 안내형: "취소하시겠어요?" > "취소"는 버튼에만

## 버튼 라벨

| 의미 | 한국어 |
|------|--------|
| 처리 시작 | "변환하기", "압축하기", "{동작}하기" |
| 다운로드 | "다운로드" |
| 취소 | "취소" |
| 다시 | "다시 처리" |
| 추가 | "파일 추가" |
| 삭제 | "삭제" |
| 닫기 | "닫기" |
| 확인 | "확인" |
| 적용 | "적용" |

도구 카드 부제는 동사 종결("...합니다") — 사용자가 행동을 인식.

## 에러 메시지

### 좋은 예
- "파일을 먼저 선택해주세요."
- "처리에 실패했습니다. 파일이 손상되었을 수 있습니다."
- "이 파일 형식은 지원하지 않습니다."
- "파일이 너무 큽니다 (150 MB). 100 MB 이하를 권장합니다."
- "암호화된 PDF 입니다. 비밀번호를 입력해주세요."

### 나쁜 예
- "오류" (정보 없음)
- "Error: ENOENT no such file or directory" (영문·기술적)
- "처리에 실패함" (반말)
- "파일 너무 큼!!!" (느낌표·반말)

## 도움말 / 설명

- 1줄로 끝낼 수 있으면 1줄
- 사용자가 결과를 미리 알 수 있게: "여러 PDF 를 하나로 합칩니다." (X "PDF 병합 도구")
- 기술 용어는 한국어 표기 우선: "워터마크", "메타데이터", "EXIF"

## 수치·단위

- 파일 크기: `2.5 MB`, `134 KB` (숫자와 단위 사이 공백)
- 시간: `12초`, `1분 30초`
- 진행률: `45%` (숫자와 % 사이 공백 없음)
- 페이지: `12 페이지` (또는 `12쪽`)

## 영문 용어 보존

다음은 한국어 음차 안 하고 영문 유지:
- PDF, JPG, PNG, MP4, GIF, SVG, JSON, CSV, OCR, QR, ZIP
- API, HTML, CSS
- Tesseract, FFmpeg (도구 외부 명칭으로 노출되는 경우)

## 카드 표시 텍스트

도구 카드는 모바일에서 좁아진다. 제목 12자 이내 권장:
- ✓ "PDF 합치기" (5자)
- ✓ "이미지 압축" (5자)
- ⚠ "여러 이미지를 하나의 PDF 로 묶기" (15자, 줄바꿈됨)

## 검색·필터 라벨

- 검색 placeholder: "도구 검색 (압축, 합치기, OCR…)"
- 카테고리 칩: 짧게 — "이미지", "PDF", "비디오"

## 도구 카드 부제 작성

```ts
// registry.ts 의 description
description: '여러 PDF 파일을 하나로 병합합니다.',  // 24자
```

- 30자 내외
- 동작 명사 + 종결 어미("...합니다")
- 부가 설명은 도구 페이지 본문에서

## 접근성 + 한국어

- `aria-label` 도 한국어 ("취소", "삭제")
- `lang="ko"` 유지 (스크린리더가 한국어 음성으로 읽음)
- 한국어 + 영어 혼용 시 공백 유지 ("Lighthouse 점수")
